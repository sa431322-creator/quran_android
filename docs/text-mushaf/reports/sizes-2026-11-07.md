# Text mushaf on every screen and font size — 2026-11-07

## Instrumented test

`app/src/androidTest/.../mushaf/MushafPageSizesTest.kt`, run on the emulator
(`./gradlew :app:connectedMadaniDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.quran.labs.androidquran.mushaf.MushafPageSizesTest`):

- **Pages (13):** 1 and 2 (opening), 50 (sura start), 77 (its header is on page 76), the five
  pages with the widest lines by V2 font metrics (575, 569, 568, 50, 600; up to 16.07 em) and the
  five with the most words (576, 303, 565, 519, 457; up to 184).
- **Sizes (12):** 360×640, 393×852, 430×932 (phones), 600×960, 800×1280, 1024×1366 dp (tablets),
  each in portrait and landscape.
- **System font scale:** 0.85, 1.0, 1.3, 2.0.

624 layouts, each checked for:
| check | result |
|---|---|
| every text line keeps its words, each word inside the line's width | pass |
| rows at least 1.75× the text size (the print: 1.78×) | pass |
| portrait never scrolls (all 15 rows on screen) | pass |
| the text column is never wider than the page | pass |
| the page's labels fit on one line in their row | pass |
| the system font scale never changes the page's text size | pass |

The test was checked against a broken engine (text made 45% too large): it reported 288 layouts
with lines running out of their width.

Found and fixed on the way:
- a page view given another page lost its lines' touch positions (now kept per composition);
- the page labels followed the system font size and wrapped; they are now sized from the page;
- a 12–13" tablet scrolled in portrait; the text is now capped by the height and centered;
- on a tablet turned to landscape the reader crashed: a page was measured with an open-ended
  width; a size far beyond the window is now taken as the window.
