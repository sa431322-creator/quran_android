## Found and fixed

1. **The page theme sheet and its menu item were in English** («Page theme», Light, Dark, Sepia,
   Match app theme): upstream's `feature/pagetheme` has Persian for two strings only. Persian
   added in `app/src/madani/res/values-fa/tasnim_overrides_strings.xml` (app resources override
   the module's, so upstream's own translation can land later without a clash).
2. **The sheet was Material's lavender**: Tasnim's color scheme did not set the surface
   *container* colors that sheets, dialogs and menus use. Set in `TasnimColorScheme` (cream by
   day, night palette by night).

## Noted, not changed

- **Reader bars stay cream on a dark page**: upstream now separates the page's appearance from
  the app theme; the bars follow the app theme. Same as upstream.
- **Stale gradient after a live screen-size change**: the shaded page gradient is cached at the
  width it was first drawn at, so resizing the emulator without restarting shows a seam
  ([tablet_stale_gradient_after_resize](2026-11-11/tablet_stale_gradient_after_resize.png)).
  Gone after a restart; upstream's Light page caches the same way. Could matter for split screen.
- **Sura rows on the Quran home are white by day**: same color as on the old Tasnim build.
- **Not covered here**: image pages (V2 images need the Tasnim server), audio playback (no
  recitation files on the emulator), bookmarks with sync. Unit tests cover bookmarks and audio.
